> 이 문서는 **운영 단계**에서 실제 사용자/이해관계자 개인정보가 얼마나 보관되고,
> 언제·어떻게 파기되며, 당사자 요청 시 어떻게 열람/정정하는지를 다룹니다.

> ⚠️ 이 문서의 법적 기준(보존기간 등)은 AI나 개발자가 임의로 확정하지 않고,
> 반드시 사람(책임자/필요시 법무 검토)이 확정합니다 — `harness_00 §4-1`
> "되돌리기 어려운 결정" 원칙의 적용 대상입니다.

## §3. 파기 절차

```mermaid
flowchart TD
    A[파기 트리거 발생] --> B{트리거 종류}
    B -->|보존기간 만료| C[자동 대상 목록 생성]
    B -->|졸업/전학| C
    B -->|본인/법정대리인 파기 요청| D[요청 본인확인]
    D --> C
    C --> E[파기 대상 사람 확인/승인]
    E --> F{승인?}
    F -- No --> G[보류 사유 기록]
    F -- Yes --> H[파기 실행 - 물리삭제 또는 익명화]
    H --> I["파기 로그 기록<br/>대상/일시/방법/승인자"]
    I --> J[관련 백업본 파기 일정 확인]
```
