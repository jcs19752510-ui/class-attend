## §0. 범위 및 목적
프랜차이즈 다지점 학원의 **출결관리**를 웹 서비스로 제공한다.
학생 등록·반 편성, 강사의 수동 출결 체크, 역할별 조회(본사/지점/강사/학부모),
학부모-자녀 연결, 개인정보 생명주기 처리까지가 1차 범위(MVP)다.

**Out of Scope (이번 범위 제외 — 이후 릴리스 검토 대상)**
- 수납/학원비 관리
- 시간표 관리
- 성적/평가 관리
- 학부모 상담 기록

## §1. 역할별 권한 매트릭스
| 역할 | 조회 범위 | 주요 권한 |
|---|---|---|
| 프랜차이즈 관리자(본사) | 전체 지점 통합 | 지점 생성/관리, 전체 통계·감사로그 조회 (`branch_id` 필터 예외 대상, ADR-001) |
| 지점 원장 | 자기 지점만 | 학생/반/강사 관리, **출결 체크(강사 대신 입력 가능, U3 §7 확정)**, 학부모-자녀 연결 승인, 지점 감사로그 조회 |
| 강사 | 자기 담당 반만 (ADR-002: `class_teacher` 매핑 기준) | 배정된 반의 출결 체크·조회 |
| 학부모 | 자기 자녀만 (원장 승인 완료 건) | 자녀 출결 조회, 계정 연결 요청 |

## §2. 핵심 엔티티 개요
> 상세 컬럼 정의는 각 단위 TRD §1에서 확정. 여기서는 개체와 관계만 정리.

- `Branch`(지점) — 프랜차이즈 관리자가 생성. 모든 하위 엔티티가 `branch_id`를 가짐(ADR-001).
- `User`(사용자) — role: `franchise_admin` / `director`(원장) / `teacher`(강사) / `parent`(학부모)
- `Student`(학생) — 이름, 생년월일, 연락처, 보호자 연락처, `branch_id`
- `Class`(반)
- `student_class`(학생-반 매핑, N:M) — ADR-002
- `class_teacher`(반-강사 매핑, N:M) — ADR-002
- `parent_student_link`(학부모-학생 연결) — 원장 승인 상태(pending/approved/rejected) 포함
- `Attendance`(출결기록) — 상태: 출석/결석/지각/조퇴/사유결석(5종), 학생·반·일자·기록자·기록시각
- `AuditLog`(감사로그) — 출결 변경 + 개인정보 조회/수정 이력, 행위자·시각·대상·변경 전후 값

## §3. 비기능 요구사항 총괄
- **동시성**: 단위 TRD에서 개별 확정 예정. 현재까지는 "동일 학생의 동일 일자 출결
  레코드에 대한 동시 수정" 정도가 유일하게 예상되는 충돌 지점 (U3에서 상세화).
- **권한**: §1 매트릭스 + ADR-001의 `branch_id` 필터링 규칙을 모든 단위가 상속.
- **감사(audit)**: 출결 변경 이력 + 개인정보(학생/보호자 연락처 등) 조회·수정
  이력까지 기록 (U7).
- **개인정보**: 수집 항목 = 이름 + 생년월일 + 연락처(학생/보호자) + 반 배정.
  보유기간 = 퇴원 후 **365일** (ADR-005, 2026-09-06 확정).
- **삭제 정책**: 계정·학생 모두 물리 삭제 없음(ADR-003) — 학생은 보유기간
  경과 시 **행 삭제가 아닌 개인정보 필드 마스킹**(ADR-005, U6 구현 완료).

## §4. 단위(Unit) 목록
> 화면 단위가 아니라 "담당자/변경 빈도가 다른 책임 경계"로 분할함(하네스 원칙 1).

| 단위 코드 | 단위명 | 핵심 기능 | 관련 역할 | TRD 상태 |
|---|---|---|---|---|
| U1 | 지점·계정 관리 | 지점 생성/폐쇄, 원장·강사·학부모 계정 발급 및 지점 배정 | 본사, 원장 | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
| U2 | 학생·반 관리 | 학생 등록/수정/퇴원 처리, 반 개설, 학생↔반·반↔강사 배정 | 원장, 강사 | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
| U3 | 출결 체크 | 강사(또는 원장)가 반별 명단에서 5종 상태로 출결 입력 | 강사, 원장 | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
| U4 | 출결 조회·통계 | 역할별 범위로 출결 현황·통계 조회 | 본사, 원장, 강사, 학부모 | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
| U5 | 학부모-자녀 연결 | 학부모 회원가입 → 연결 요청 → 원장 승인 | 학부모, 원장 | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
| U6 | 개인정보 생명주기 | 퇴원 처리 트리거(365일 후 마스킹, ADR-005) | 시스템(franchise_admin 트리거) | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
| U7 | 감사로그 | 출결 변경 + 개인정보 조회·수정 이력 기록 및 조회 | 본사, 원장 | **확정 + 구현 완료**(2026-09-06, 테스트 통과) |
