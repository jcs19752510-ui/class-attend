# 동의 문구 초안 — class-attend

> `docs/legal/privacy_policy_draft.md`와 마찬가지로 법무 검토 전 게시 금지.
> UI(`src/app/signup/page.tsx`, `src/app/(app)/students/page.tsx`)에서
> 참조하는 짧은 동의 문구입니다.

## 1. 학부모 회원가입 동의 (필수)
> 화면 표시 위치: `/signup` 체크박스 옆

```
[필수] 개인정보 수집·이용 동의

- 수집 항목: 이메일, 이름, 연락처(선택)
- 수집 목적: 서비스 계정 생성·로그인, 자녀 출결 조회 서비스 제공
- 보유 기간: 회원 탈퇴 시까지
- 동의를 거부할 권리가 있으며, 동의 거부 시 회원가입이 제한됩니다.

자세한 내용은 개인정보처리방침을 확인하세요.
```

## 2. 학생 등록 시 보호자 동의 확인 (필수, 원장이 체크)
> 화면 표시 위치: `/students` 학생 등록 폼 체크박스 옆
> **주의**: 이 체크는 원장이 "보호자로부터 사전에 동의를 받았음을
> 확인"하는 것이지, 보호자가 화면에서 직접 동의하는 것이 아닙니다.
> 이 확인 방식이 법적으로 충분한지는 `legal_review_checklist.md` §2 참고.

```
[필수] 보호자 개인정보 수집·이용 동의 확인

- 수집 항목: 학생 이름, 생년월일, 연락처(선택), 보호자 연락처
- 수집 목적: 학원 출결 관리
- 보유 기간: 퇴원 처리 후 365일(이후 개인정보 마스킹 처리)
- 학생이 만 14세 미만인 경우, 법정대리인(보호자)의 동의가 필요합니다.

원장은 위 사항에 대해 보호자로부터 사전 동의를 받았음을 확인합니다.
```
